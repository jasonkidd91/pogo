Pokémon GO

Promo Codes

Every promo code LeekDuck currently lists as active, fetched live from their Promo Codes page. Redeem a code at the official Pokémon GO Web Store — Copy puts it on your clipboard, Redeem opens the page with it filled in. You can redeem more than one code, but each works once per account, and every code eventually expires.

This page has no sign-in gate and nothing here is tracked on your account — a promo code is either redeemed at Niantic's store or it isn't, and this site has no way to know which. The NEW tag and the dot on this page's nav link are purely local to this browser: they mark codes you haven't opened this page to see yet, not codes you haven't redeemed.
